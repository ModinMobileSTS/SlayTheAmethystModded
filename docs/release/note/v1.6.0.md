## 新特性
- 重写帧同步逻辑，适配动态刷新率，画面更流畅，功耗更低。
- 优化 Ram Saver，减少内存消耗，减少大量小卡顿。

## 修复
- Easytier 运行库缺失导致无法联机的问题。
- 资源包无法通过文件夹上的批量开关改变状态的问题。
- 修复从创意工坊下载的模组丢失依赖状态的问题。感谢 @月影 提出！

## 性能数据

相较 `v1.5.9`，本版本进一步优化了启动、战斗和内存表现：

* `>=33ms` 卡顿帧减少约 **32%**
* `>=50ms` 卡顿帧减少约 **27%**
* `>=100ms` 严重卡顿减少约 **43%**
* 战斗中的 `>=100ms` 卡顿由平均 **3.3 次降至 0.7 次**
* 稳定阶段 JVM 内存占用降低约 **54%**，减少约 **287MB**
* 稳定阶段总内存占用降低约 **25%**，减少约 **413MB**
* GC 总暂停时间降低约 **22%**
* GC 次数降低约 **14%**
