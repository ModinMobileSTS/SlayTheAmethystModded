## 新特性
- 模组补丁页支持浏览原模组。
- 支持给模组排序。
- 优化模组页排版和操作。
- 尽力请求设备高刷，新增强制高刷模式。
- 优化 Agent 工作速度。

## 修复
- 创意工坊模组更新确认不再等待更新日志加载，日志加载失败或重试也不影响更新。
- 修复某些社区补丁使用同一 modid 会崩溃的问题。
- Steam 时长上报在网络断开后不会恢复的问题。
- 部分模组出现 Couldn't load file: wild.png at com.badlogic.gdx.graphics.Texture 的报错问题。
- 修复临时凭据读取失败导致 Steam 游戏在线状态停止更新的问题。
