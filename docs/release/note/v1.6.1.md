# v1.6.1

适用于 1.6.1 正式版及其所有 hotfix 版本。

## 新特性
- 隆重推出 AI 编辑模组的功能 —— Amethyst Agent，可以完成自然语言对模组修改以及汉化！
- 隆重推出小游戏启动界面，可以在启动的时候游玩我们开发的小游戏！
- 现在设置中可以解开帧数限制了。
- 优化游戏页冷加载速度，避免卡顿。
- 调整一些图标外观。
- 现在可以在游戏页选择渲染后端。
- 添加游戏页卡片动效。
- 联机房间支持查看密码和分享房间。
- 优化市场加速链路逻辑。
- 提供了 superfastmode 模组无法抓鸟笼等的修复补丁（需要重新导入）。

## 修复
- 提供了 superfastmode 模组无法抓鸟笼等的修复补丁（需要重新导入）。
- 被踢出后，会重复显示弹窗的问题。
- 模组有时会从市场下载态变为外部导入态的问题。
- Easytier 连接失败的信息不再持久存储。
- 动态刷新率设备最高 fps 会被自动切换为 60 的问题。
- 启动器的一些性能问题。
