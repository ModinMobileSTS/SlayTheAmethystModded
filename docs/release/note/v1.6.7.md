## 新特性
- 重做「画面与分辨率」设置。显示区域和渲染清晰度可以分开调，支持拖动四角、输入像素尺寸，以及铺满屏幕、1080P、720P 和 4:3 预设。
- 模组启动方案支持手动保存。关闭自动保存后，游戏仍按当前勾选启动，不会覆盖已保存的方案，随时可以恢复。
- 悬浮键盘支持单独添加反引号、`~` 等标点键，按 `~` 不用再配合 Shift 就能打开 BaseMod 的默认控制台。
- 模组编辑器新增全屏菜单，可以新建、切换和删除历史会话，查看 Token 用量、缓存命中和执行记录，也能直接调整模型配置。
- 模组编辑器支持按模型配置可用的推理强度档位。
- 点击模组卡片上的社区徽标可直达社区补丁页，已安装且没有更新的补丁可以直接开关。下载时会显示正在连接或切换线路。
- 模型列表获取和连接测试失败时，可以复制脱敏诊断信息。

## 修复
- 修复开启 RamSaver 后，部分 TGA 或没有扩展名的贴图加载失败，导致游戏崩溃的问题。
- 修复模组编辑器明明还在持续收到模型输出，却因达到固定时限而提前中断的问题。
- 修复部分模型的思考内容混进正文，以及 Responses 接口未报告缓存数据时被误记为 0% 的问题。
- 修复模型配置偶尔读回旧设置的问题，并拦截误粘贴到 API 地址里的整条命令。
- 修复部分弹窗的输入框不显示光标和文字选择手柄的问题。
- 修复社区补丁改名后重新上传会留下重复条目的问题（服务端更新后生效）。
