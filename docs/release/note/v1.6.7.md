## 新特性
- 重做画面与分辨率设置，支持分别调整显示区域和渲染分辨率。
- 模组方案支持手动保存和恢复。
- 悬浮键盘支持单独添加符号键。
- 模组编辑器新增编辑器菜单，支持管理历史会话、查看用量统计与历史轨迹。
- 模组编辑器支持配置可用推理强度档位。
- 点击模组卡片上的社区补丁徽标可直接打开模组补丁页，并支持直接开关已安装的补丁。
