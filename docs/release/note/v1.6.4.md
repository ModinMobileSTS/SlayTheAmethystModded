该版本新增了社区模组仓库，欢迎大家使用启动器的模组编辑器用自然语言制作补丁和模组附属！无论是模组汉化还是模组修复亦或是模组增强都欢迎分享！期待大家的模组补丁！

## 新特性
- 现在支持上传通过模组编辑器 amethyst agent 制作的模组补丁到补丁仓库，也支持所有玩家下载他人制作的模组，如果某个模组有人上传了补丁，将在模组卡片上以徽标的方式显示出来，可以选择安装。
- 多项模组编辑器 Amethyst Agent 的改进，包括并发工具调用、提高请求缓存率（节省成本）、提升后台留存能力、支持识图、支持待发消息队列等，总体提升约提升200%的工作速度。
- 模组编辑器支持查看其他模组的源代码。
- 新增多个模组编辑器的免费调用渠道。
- 大幅优化模组编辑器的前端性能，大幅减少卡顿问题。
- 一些前端调整。

- 修复小游戏的性能问题。
