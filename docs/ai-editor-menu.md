# 模组编辑器菜单

编辑器右上角的菜单按钮打开独立的全屏菜单，顶部导航支持点击与横向滑动，返回后保留编辑器草稿。
菜单内保留左上角返回箭头和系统返回操作，不显示右上角“返回对话”按钮。

对话与菜单之间采用与启动器整页导航一致的 420ms 横向切换：进入时菜单从右侧滑入、对话向左滑出；返回时方向相反。菜单内部仍由分页组件处理滑动，不叠加整页切换动画。

页面包括：

- **历史会话列表**：当前模组的会话，按原存储顺序逆序排列，不提供搜索框。支持新建、切换会话，每条会话最右侧的三点菜单提供带垃圾桶图标的“删除”操作，确认后删除。为沿用现有执行约束，任务运行时不允许新建、切换或删除会话。没有可靠会话时间或轮次数的旧摘要不会伪造这些信息。
- **会话数据统计**：当前会话的已报告 token 用量、输入/输出分项、用量报告覆盖、输出速度、执行耗时、上下文估算和缓存命中。部分请求未报告时累计值显示 `≥`；完全缺失的用量显示 `—`，不将未知用量记作零。
- **模型配置**：复用全局模型设置（连接、凭据、模型列表与连接测试），并提供当前服务地址/模型对应的上下文输入预算、输出预留。全局设置沿用防覆盖的局部更新与保存重试机制；预算通过保存按钮应用到下一任务。
- **对话历史轨迹**：复用真实执行步骤，按轮次展开模型请求、工具调用、压缩和错误，保留旧会话兼容和长列表懒加载。

输入区沿用原有布局：上排为附件、思考强度和发送/停止，下排为模型选择、上下文圆环和 `token/s`。上下文圆环紧邻 `token/s` 左侧，仍可打开详情、压缩上下文；`token/s` 进入统计页。

## 推理强度

设置页提供 `none / minimal / low / medium / high / xhigh / max` 多选，默认启用 `low / medium / high / xhigh / max`。编辑器仅在启用集合中单选一次请求所用的档位；至少保留一项。移除当前档位时回退到剩余集合的第一项（按预置顺序），配置持久化，重新打开后仍生效。设置页不显示已选数量或滑动提示文案。

思考强度弹窗沿用原有毛玻璃面板、能量图标和连续拖动、松手吸附的滑块，也可点击档位标签。滑块仅对应启用的档位，只有一档时禁用滑动、保留标签选择。多档时面板按窗口宽度扩展，标签自动换行以适配窄屏和大字体；保留“配置可用档位”入口。

预置不意味着服务端支持；界面明确提示：有的模型不支持部分推理强度，启动器无法探测，请根据模型实际支持的推理强度进行配置。档位按名称原样发送，不自动试探、替换或重试为其他档位。

旧版 `OFF` 保留其省略 provider reasoning 参数的行为（以及现有 DeepSeek 专用禁用配置），不悄悄变成新的 `none`。旧用户未重新配置集合前可继续使用此选择；显式配置集合后进入新预置集合。`MEDIUM` 现在是独立真实档位，不再映射到 `HIGH`。

## 删除会话

删除会清除会话消息、附件、工具调用、执行轨迹、上下文和已结束任务记录，不会删除生成的补丁模组。删除非当前会话不改变当前对话；删除当前会话会切换到新的空白会话，菜单保持打开。数据保存失败时保留列表项并提示重试。

存储层在 SQLite 写事务内再次核对目标任务状态，拒绝删除运行中或尚未释放执行占用的会话。清除记录后保留一个无对话内容的数据库墓碑，防止延迟写入或旧 JSON 迁移重新导入已删除会话。删除不是磁盘安全擦除。

## 验证

离线单元测试覆盖配置持久化与旧记录、乱序局部写入、档位回退、部分用量统计和本机 MockWebServer 的档位请求值。Compose 仪器测试覆盖多选到单选联动、最后一项保护、导航点击、横向滑动和无搜索框的会话三点删除菜单；存储仪器测试覆盖删除、其他会话保留、运行任务保护与防止重新导入。离线编译仪器测试不等于在设备上运行通过。
